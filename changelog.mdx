## How to Upgrade

<Callout kind="info">
  Always back up your configurations before upgrading. Test in a staging environment first.
</Callout>

<Steps>
  <Step title="Install Latest SDK" icon="download">
    Update to the newest version using your package manager.

    <CodeGroup tabs="npm,yarn,pnpm">
      ````bash
      npm install @percepteye/flywheel@latest
      ````

      ````bash
      yarn add @percepteye/flywheel@latest
      ````

      ````bash
      pnpm add @percepteye/flywheel@latest
      ````
    </CodeGroup>
  </Step>
  <Step title="Update Configuration" icon="settings">
    Migrate your config to the new `{API_KEY}` format.

    ````javascript
    // Old format
    const config = { token: 'old-token' };

    // New format
    const config = {
      apiKey: process.env.PERCEPTEYE_API_KEY, // Use YOUR_API_KEY here
      endpoint: 'https://api.percepteye.ai/v1'
    };
    ````

    <Callout kind="tip">
      Set `PERCEPTEYE_API_KEY` in your environment variables.
    </Callout>
  </Step>
  <Step title="Restart Services" icon="refresh-cw">
    Redeploy your agents and verify the flywheel loop.

    ````bash
    percepteye-agent restart --all
    ````
  </Step>
</Steps>
